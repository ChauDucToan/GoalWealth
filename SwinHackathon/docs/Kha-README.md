# Bộ Tài Liệu `Kha-*`

Đây là bộ tài liệu bổ sung cho các file `HeheBoiz-*` đang có trong thư mục `docs`.

Nếu nhóm `HeheBoiz-*` thiên về:

- lịch sử repo
- kiến trúc tổng quan
- flow tổng thể
- một số feature lớn đã có trước đó

thì nhóm `Kha-*` tập trung vào:

- các hạng mục đã được yêu cầu trực tiếp trong đợt làm việc này
- các màn UI đã dựng theo design
- các refactor dựa trên feedback kiểm thử
- cách triển khai cụ thể và phương pháp thực thi

## Ghi chú

- Bộ tài liệu này bám theo source code hiện tại và chuỗi yêu cầu đã được triển khai trong đợt làm việc gần đây.
